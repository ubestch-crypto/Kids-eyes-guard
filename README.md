**「童护守望」**的智能儿童设备时间管控与健康视力守护应用，支持手机与平板多端适配、PWA桌面安装发布、家长远程临时密码解锁与2分钟前置倒计时提醒，并融合了多项人性化功能。

一、 核心功能设计与实现
2分钟前置锁屏智能预警（核心体验）
温和倒计时弹窗：当剩余使用时间进入最后 2分钟（120秒） 时，孩子端桌面会自动弹出柔和但醒目的倒计时浮窗，并伴有舒缓双音提示音（Web Audio API合成，无需额外加载音频文件）。
心理过渡与尊重：提示语引导孩子*“请及时保存作业或绘本进度，准备喝水休息眼睛哦~”*，彻底解决以往设备“猝然黑屏断电”给孩子带来的挫败感与亲子冲突。

快速处理通道：弹窗中直接提供*“申请延长15分钟”、“输入家长临时密码”与“准备休息”*三大入口。

便捷体验按钮：顶部常驻**「⚡ 立即体验 2 分钟倒计时锁屏预警」**快捷键，点击后直接将计时调至125秒，5秒内即可直观体验预警全流程。

动态临时密码与远程弹性控制

动态 6 位一次性密码（OTP）：家长可在控制端根据不同场景（如*“完成口算打卡”、“学校英语网课延时”*）生成有效时长为 15/30/45/60 分钟的临时通行码。

用后即焚与安全防盗：孩子输入后立即生效延时，密码自动标记为“已使用”并记录日志，避免孩子窥探主控制密码导致防沉迷失效。

一键远程管控：支持家长端即时下发**“一键强制锁屏”（可自定义温馨提醒语如*“该吃晚饭了”*）、“远程一键解锁 / 加时”**。

全功能 PWA 可安装与免审发布
即装即用：完整配置了 Web App Manifest、192px/512px/Maskable 高清图标、iOS Apple Touch 图标与 Service Worker 离线守护。
原生桌面体验：顶部提供**「安装到设备桌面 (PWA)」**按钮，安卓/桌面设备支持一键直接安装到系统桌面；苹果 iPad/iPhone 则提供图文并茂的“添加到主屏幕”指引，全屏沉浸运行。
双机实时联动演示（同屏对比）
顶部提供**「双机联动演示」、「家长管控端」、「孩子设备端」**三种视图。在联动模式下，左侧为家长手机控制台，右侧为孩子平板高仿真外框，家长端点击锁屏或生成密码，孩子端通过 BroadcastChannel 实时无延迟响应。

二、 拓展思维：人性化创新功能
为了避免传统防沉迷应用“冰冷压制、激发亲子矛盾”的弊端，应用在场景上做了深度拓展：
20-20-20 科学护眼操与视力守护
锁屏状态或疲劳时内置互动式护眼操：遵循国际 20-20-20 护眼法则（用眼20分钟，远眺20英尺外景物20秒），通过动效引导孩子完成闭眼深呼吸、眼球远眺转动与手心热敷，化锁屏为视力保养。
“以自律换时间”正向习惯激励经济（以奖代罚）
将屏幕时间转化为自律契约，孩子完成*“跳绳 300 次”、“背诵一首古诗”、“整理书桌玩具”*等良好生活习惯后可在设备端打卡，家长审核后一键奖励对应屏幕时长。

双向温情延时求助
孩子在预警或锁屏期，可一键向家长提交延时理由（如*“绘本还剩最后2页”、“需要发送打卡语音”*），家长手机端立即弹出审批横幅，支持一键批准或温和留言。

锁屏亲情直拨热线
在全屏锁屏状态下，始终保留直拨爸爸、妈妈电话的亲情绿色通道，确保孩子独处或遇到紧急情况时联络永不掉线。
